💳 Virtual ATM Application (Java)

📌 Overview
This is a console-based ATM simulation system built using Core Java.
It allows users to log in with their account number and PIN, perform basic banking operations such as deposit, withdrawal, and balance inquiry, and view mini statements.
The project demonstrates Object-Oriented Programming (OOP) concepts, exception handling, and data management using Collections.

✨ Features
👤 User

Secure login with Account Number & PIN

Check balance anytime

Deposit money into the account

Withdraw funds with validation

Print transaction receipt

View mini statement (with date and time)

Apply interest (for Savings Accounts only)

🏦 Account Types

Savings Account

Earns interest

Enforces a minimum balance

Current Account

No interest

Applies a penalty if balance drops below the minimum

🛠️ Technologies Used

Java (Core OOP)

Collections Framework (HashMap, ArrayList)

Date & Time API (SimpleDateFormat)

Console-based UI (using Scanner)
